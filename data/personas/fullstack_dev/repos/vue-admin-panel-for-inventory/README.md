# vue-admin-panel-for-inventory

Vue admin panel for inventory - a reactive admin UI over a small Python API with barcode lookups.

## Stack
- Vue.js
- Flask
- REST API

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for BoltBox Hardware (synthetic) in 2023. Outcome: stock discrepancies down 75% after two months.
