# django-crm-for-a-property-agency

Django CRM for a property agency - a Django app with an admin panel, lead pipeline and scheduled email reminders.

## Stack
- Django
- PostgreSQL
- REST API

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Skyline Estates (synthetic) in 2022. Outcome: lead response time fell from 1 day to 2 hours.
