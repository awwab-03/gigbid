# restaurant-ordering-pwa

Restaurant ordering PWA - an installable ordering app with card checkout and a kitchen screen.

## Stack
- Next.js
- Tailwind CSS
- Stripe

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Tandoor House (synthetic) in 2025. Outcome: direct orders reached 31% of volume within 3 months.
