# mongodb-event-store-for-an-iot-dashboard

MongoDB event store for an IoT dashboard - time-bucketed documents and a live dashboard per site.

## Stack
- MongoDB
- Node.js
- React

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for SunGrid Solar (synthetic) in 2024. Outcome: faults spotted 2 days sooner on average.
