# supabase-migration-for-a-booking-app

Supabase migration for a booking app - moved data to Postgres with row-level security and rebuilt the booking flow.

## Stack
- Supabase
- Next.js
- PostgreSQL

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Haven Stays (synthetic) in 2025. Outcome: monthly backend cost cut by 60%; zero downtime cut-over.
