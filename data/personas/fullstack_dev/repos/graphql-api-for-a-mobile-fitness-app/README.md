# graphql-api-for-a-mobile-fitness-app

GraphQL API for a mobile fitness app - a single typed schema with data loaders and field-level auth.

## Stack
- GraphQL
- Node.js
- TypeScript

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for FitLoop (synthetic) in 2024. Outcome: mobile releases went from monthly to weekly.
