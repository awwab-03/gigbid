# containerised-deployment-pipeline

Containerised deployment pipeline - container images, automated tests and blue-green deploys.

## Stack
- Docker
- CI/CD
- AWS

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Launchpad Labs (synthetic) in 2024. Outcome: deploys went from 40 minutes and manual to 6 minutes and automatic.
