# Vue admin panel for inventory

**Client:** BoltBox Hardware (synthetic) | **Industry:** Retail | **Duration:** 5 weeks | **Date:** 2023-02

## The problem
The client was a hardware store chain reconciling stock by phone.

## What I did
My approach: a reactive admin UI over a small Python API with barcode lookups. The main stack was Vue.js, Flask, REST API. Under the hood this meant a relational database with proper migrations and indexes. We looked at React early on but decided not to use it for this engagement.

## Result
The work stock discrepancies down 75% after two months.

## What I learned
Ship a thin end-to-end slice first, then improve the slowest part.
