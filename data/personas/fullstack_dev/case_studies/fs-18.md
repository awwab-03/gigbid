# FastAPI backend for an ML demo

**Client:** Vision Lab (synthetic) | **Industry:** AI | **Duration:** 2 weeks | **Date:** 2025-08

## The problem
The client was a research group whose model only ran in a notebook.

## What I did
My approach: a typed API and a simple React front end with upload progress. The main stack was FastAPI, React. Under the hood this meant a containerised build that runs the same everywhere. It also needed scripting the pipeline end to end. 

## Result
The work used by 300 external testers in a week.

## What I learned
Keep the client's operators in the loop weekly; their feedback changed the design twice.
