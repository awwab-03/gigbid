# End-to-end test suite for a fintech web app

**Client:** Paywise (synthetic) | **Industry:** Fintech | **Duration:** 3 weeks | **Date:** 2024-07

## The problem
The client was a fintech shipping regressions in its signup flow.

## What I did
My approach: unit tests for components and browser tests for the money flows, run on every pull request. The main stack was Playwright, Jest, TypeScript. Under the hood this meant every push tested and deployed automatically. 

## Result
The work production incidents from the signup flow fell from 5 a month to 0 over a quarter.

## What I learned
Ship a thin end-to-end slice first, then improve the slowest part.
