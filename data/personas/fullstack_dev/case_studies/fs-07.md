# Firebase chat for a community app

**Client:** Craftfolk (synthetic) | **Industry:** Social | **Duration:** 3 weeks | **Date:** 2022-06

## The problem
The client was a hobby community needing chat without running servers.

## What I did
My approach: realtime chat rooms with hosted auth and moderation rules. The main stack was Firebase, React. Under the hood this meant interactive browser code. We looked at Supabase early on but decided not to use it for this engagement.

## Result
The work 12,000 monthly active users with zero server management.

## What I learned
Write the data checks before the model or the UI; most surprises came from the data.
