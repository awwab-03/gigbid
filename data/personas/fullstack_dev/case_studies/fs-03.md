# Real-time logistics tracking

**Client:** SwiftHaul Logistics (synthetic) | **Industry:** Logistics | **Duration:** 5 weeks | **Date:** 2024-01

## The problem
The client was dispatchers refreshing a spreadsheet to see truck locations.

## What I did
My approach: a live map that receives positions pushed from the server every few seconds. The main stack was React, Node.js. Under the hood this meant live updates pushed to the browser without refresh. It also needed an in-memory cache in front of the database. Behind the scenes I set up a document store for flexible records. 

## Result
The work dispatch call volume down 40%.

## What I learned
Write the data checks before the model or the UI; most surprises came from the data.
