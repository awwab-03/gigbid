# inventory-kpi-dashboard-in-excel

Inventory KPI dashboard in Excel - pivot models, lookups and a printable KPI sheet.

## Stack
- Excel
- Dashboarding

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Indus Textiles (synthetic) in 2022. Outcome: freed PKR 4 million of tied-up inventory within a quarter.
