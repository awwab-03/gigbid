# e-commerce-cohort-and-ltv-dashboard

E-commerce cohort and LTV dashboard - monthly cohorts, repeat-purchase curves and LTV by first product.

## Stack
- Looker Studio
- BigQuery
- SQL

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Kettle & Co (synthetic) in 2025. Outcome: shifted acquisition to two hero products with 1.8x higher LTV.
