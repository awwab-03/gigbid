# data-cleaning-of-a-2-million-row-crm-export

Data cleaning of a 2-million-row CRM export - fuzzy matching, address standardisation and a review sheet for edge cases.

## Stack
- Data cleaning
- Python
- pandas

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Prime Distributors (synthetic) in 2023. Outcome: 2.1 million rows reduced to 640,000 unique customers with an audit trail.
