# marketing-attribution-warehouse

Marketing attribution warehouse - joined ad spend with web events and orders, then built tested models for each channel.

## Stack
- BigQuery
- SQL
- GA4

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Wildthread Apparel (synthetic) in 2023. Outcome: reallocated 18% of ad budget and lowered cost per order by 22%.
