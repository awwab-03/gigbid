# redshift-cost-and-performance-tuning

Redshift cost and performance tuning - sort and distribution keys, materialised aggregates and query rewrites.

## Stack
- Redshift
- SQL

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for StreamWave Media (synthetic) in 2024. Outcome: median dashboard query from 110 s to 9 s and 30% lower cluster spend.
