# executive-sales-dashboard

Executive sales dashboard - a star schema and one-page KPI report with drill-through by region.

## Stack
- Power BI
- SQL
- Dashboarding

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for UrbanMart (synthetic) in 2023. Outcome: weekly reporting time fell from 6 hours to 20 minutes.
