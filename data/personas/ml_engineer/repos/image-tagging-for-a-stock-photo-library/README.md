# image-tagging-for-a-stock-photo-library

Image tagging for a stock-photo library - a multi-label classifier fine-tuned from a pretrained backbone.

## Stack
- Computer vision
- PyTorch

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Frameworks Media (synthetic) in 2023. Outcome: tag precision 0.88 at 5 tags per image; search usage doubled.
