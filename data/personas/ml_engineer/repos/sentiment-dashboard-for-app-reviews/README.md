# sentiment-dashboard-for-app-reviews

Sentiment dashboard for app reviews - a pretrained sentiment model plus topic clustering, refreshed nightly.

## Stack
- NLP
- Hugging Face Transformers

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for PixelForge Studio (synthetic) in 2023. Outcome: surfaced 3 crash-related themes that drove the next two releases.
