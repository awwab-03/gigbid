# retail-demand-forecasting-for-300-skus

Retail demand forecasting for 300 SKUs - per-SKU forecasters with holiday regressors, retrained weekly.

## Stack
- Python
- Time series forecasting
- Prophet

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for FreshMart (synthetic) in 2023. Outcome: reduced MAPE from 31% to 18% and cut waste on perishables by 12%.
