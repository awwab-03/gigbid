# multi-agent-research-assistant

Multi-agent research assistant - a planner, researcher and writer agent with a human review step before export.

## Stack
- Python
- LangGraph
- RAG

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for Meridian Advisory (synthetic) in 2025. Outcome: first drafts in 15 minutes, analysts kept 70% of generated text after review.
