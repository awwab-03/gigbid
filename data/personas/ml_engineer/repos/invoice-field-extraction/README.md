# invoice-field-extraction

Invoice field extraction - OCR plus entity extraction with validation rules for totals and dates.

## Stack
- NLP
- spaCy
- Python

## Quickstart
```
git clone <repo>
make install && make run
```

## Notes
Built for LedgerPoint (synthetic) in 2024. Outcome: 94% field accuracy, saving roughly 30 staff hours a week.
