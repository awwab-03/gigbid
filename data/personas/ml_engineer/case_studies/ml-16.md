# Image tagging for a stock-photo library

**Client:** Frameworks Media (synthetic) | **Industry:** Media | **Duration:** 4 weeks | **Date:** 2023-05

## The problem
The client was 120,000 photos with no searchable tags.

## What I did
My approach: a multi-label classifier fine-tuned from a pretrained backbone. The main stack was Computer vision, PyTorch. Under the hood this meant exporting the model to a portable runtime for CPU inference. It also needed scripting the pipeline end to end. We looked at YOLO early on but decided not to use it for this engagement.

## Result
The work tag precision 0.88 at 5 tags per image; search usage doubled.

## What I learned
Keep the client's operators in the loop weekly; their feedback changed the design twice.
