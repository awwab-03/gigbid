# Model training on Amazon with a hosted endpoint

**Client:** CareBridge Clinics (synthetic) | **Industry:** Healthcare | **Duration:** 5 weeks | **Date:** 2024-12

## The problem
The client was a clinic network needing no-show predictions inside their existing cloud.

## What I did
My approach: managed training jobs and a real-time endpoint behind their API gateway. The main stack was AWS SageMaker, scikit-learn, Model evaluation. Under the hood this meant a containerised build that runs the same everywhere. It also needed hosting on Amazon's cloud with object storage and managed databases. We looked at Kubernetes early on but decided not to use it for this engagement.

## Result
The work no-show prediction AUC 0.84; reminder calls targeted to the riskiest 20% of bookings.

## What I learned
Keep the client's operators in the loop weekly; their feedback changed the design twice.
