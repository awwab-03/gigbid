# Multi-agent research assistant

**Client:** Meridian Advisory (synthetic) | **Industry:** Consulting | **Duration:** 6 weeks | **Date:** 2025-01

## The problem
The client was analysts spending a day per market brief.

## What I did
My approach: a planner, researcher and writer agent with a human review step before export. The main stack was Python, LangGraph, RAG. Under the hood this meant a typed async Python API with auto-generated docs. It also needed an in-memory cache in front of the database. Behind the scenes I set up a containerised build that runs the same everywhere. 

## Result
The work first drafts in 15 minutes, analysts kept 70% of generated text after review.

## What I learned
Ship a thin end-to-end slice first, then improve the slowest part.
